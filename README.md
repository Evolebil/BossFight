# 🎮 Boss Fight

2D-платформер в жанре boss rush на **C++20 + SDL2**. Три уровня, у каждого свой босс со своей механикой.

| Уровень | Босс | Особенность |
|---|---|---|
| 1 | **Голем** | две фазы: после «смерти» возрождается с новыми атаками (рывок, прыжок-удар, телепорт-лазер) |
| 2 | **Самурай → Лучник** | Самурай парирует и кидает бомбы; после его смерти выходит Лучник с залпами клонов |
| 3 | **Смерть Ночи** | 4 фазы: неуязвима наверху, пока не убито 5 миньонов (фиолетовая полоса), потом спускается в ближний бой; лучники на платформах |

## ✨ Возможности

- **6 сложностей**: Нуб, Легко, Нормально, Сложно, Мастер, ХАРДКОР — разные урон, HP и число жизней.
- **Звёзды за уровень** (до 3): убить босса · уложиться в 3 минуты · пройти без урона.
- **Свои звёзды у каждой сложности** — цвета радуги: Нуб 🔴 · Легко 🟠 · Нормально 🟡 · Сложно 🟢 · Мастер 🔵 · ХАРДКОР 🟣.
- **Блокировка уровней**: уровень открывается, только когда предыдущий пройден **на этой же сложности**. Превью босса остаётся силуэтом, пока его уровень не пройден на выбранной сложности.
- Автосохранение раз в минуту, именованные сохранения (до 12), быстрое сохранение/загрузка.
- Переназначение управления, громкость, яркость, полноэкранный режим (F11).
- Отладка: **H** — показать хитбоксы, **K** — мгновенно убить босса.

## 🎮 Управление (по умолчанию)

| Клавиша | Действие |
|---|---|
| A / D | Движение |
| Пробел | Прыжок |
| S | Пригнуться / спрыгнуть с платформы |
| ЛКМ | Атака (комбо из 3 ударов) |
| ПКМ | Магия (тратит ману) |
| Shift | Рывок |
| F | Щит |
| R / X / Z | Рестарт / быстрое сохранение / быстрая загрузка |
| Esc | Пауза |
| F11 | Полноэкранный режим |

Всё, кроме Esc и F11, меняется в «Настройках».

## 🛠️ Сборка

### Linux

Нужны: компилятор с C++20 (GCC 11+ / Clang 14+), CMake 3.16+, Ninja (или make), pkg-config, SDL2, SDL2_image, SDL2_ttf, SDL2_mixer.

```bash
# Arch
sudo pacman -S cmake ninja sdl2 sdl2_image sdl2_ttf sdl2_mixer
# Debian / Ubuntu
sudo apt install cmake ninja-build pkg-config libsdl2-dev libsdl2-image-dev libsdl2-ttf-dev libsdl2-mixer-dev
```

```bash
cmake -S . -B build/Desktop_Release -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build/Desktop_Release
cd bin && ./BossFight
```

Исполняемый файл и копия `assets/` складываются в `bin/`. Запускать нужно **из папки `bin/`** — пути к ресурсам и сохранениям относительные.

### Windows (кросс-сборка из Linux через MinGW-w64)

```bash
cmake -S . -B build/MinGW_Windows_Cross_Release -G Ninja \
      -DCMAKE_BUILD_TYPE=Release -DCMAKE_TOOLCHAIN_FILE=toolchain-mingw64.cmake
cmake --build build/MinGW_Windows_Cross_Release
./package-windows.sh   # докладывает в bin/ все нужные .dll
```

Нужны пакеты MinGW-версий SDL2 (`/usr/x86_64-w64-mingw32`). Папку `bin/` с `BossFight.exe`, `.dll` и `assets/` можно переносить на Windows целиком.

## 💾 Файлы сохранений (в `bin/`)

| Файл | Что хранит |
|---|---|
| `save.bin` | звёзды по всем сложностям и уровням, выбранная сложность |
| `autosave.txt` | автосохранение текущего боя |
| `save<N>_<имя>.txt`, `saves_index.txt` | именованные сохранения и их список |

Кнопка «Сброс» на экране выбора уровня обнуляет звёзды на всех сложностях.

## 🗂️ Структура

```
characters/   игрок, боссы, миньоны
levels/       карты уровней (тайлы, коллизии, лестница уровня 3)
menu/         сцены: заставка, меню, выбор уровня, бой, настройки, сохранения, титры
utils/        анимации, камера, коллизии, ввод, звук, текстуры, сохранения
config/       настройки, сложности, прогресс
ui/           кнопки, слайдеры, текст
assets/       спрайты, звуки, музыка, шрифты
```
