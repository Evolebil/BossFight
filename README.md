## 📦 Как запустить на Windows

### Вариант 1: Скачать готовый EXE

1. **Скачай release-архив** с GitHub:
   - Зайдите в [реleases](https://github.com/ваш-username/BossFight/releases)
   - Скачайте файл `BossFight-Portable.zip`

2. **Извлеките архив** в любую папку (например: `C:\Games\BossFight`)

3. **Запустите игру**:
   - Дважды кликните по `BossFight.exe`
   - Или создайте ярлык на рабочем столе

### Вариант 2: Собрать самостоятельно

Если вы хотите собрать проект сами:

1. **Установите MinGW-w64**
   - Скачайте: https://www.mingw-w64.org/downloads/
   - Выберите версию: **x86_64-64-bit-posix-seh**
   - Распакуйте в `C:\mingw64`

2. **Добавьте в PATH**
   - Откройте "Системные переменные"
   - Добавьте в PATH: `C:\mingw64\bin`

3. **Соберите проект**
   - Откройте `build_win.bat` в блокноте
   - Запустите из командной строки в папке проекта
   - Или просто запустите `build_win.bat`

4. **Готовый EXE** будет в папке `bin\`

## 🐛 Проблемы и решения

### "Отказ в доступе"
- Закройте папку в антивирусе
- Запустите от имени администратора

### "Не найдено SDL2.dll"
- Убедитесь, что скачали release-архив с GitHub
- Все DLL должны быть в одной папке с EXE

### "Black screen"
- Обновите драйверы видеокарты
- Попробуйте в режиме совместимости (Windows 8)
